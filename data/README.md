# Dataset

The CSV in this folder is the UCI Machine Learning Repository **Maternal Health Risk** dataset (Dataset ID 863).

Source: https://archive.ics.uci.edu/dataset/863/maternal+health+risk

License: CC BY 4.0.

Citation:
Ahmed, M. (2020). *Maternal Health Risk* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5DP5D

The dataset contains physiological measurements and an ordinal `RiskLevel` target. It contains no direct student identifiers from the original coursework files.
